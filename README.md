# Тихий день

Небольшой личный дневник эмоций, состояний и субъективного цвета дня. Интерфейс полностью на русском, работает без сервера и не делает психологических выводов — он только показывает сохранённые пользователем наблюдения.

## Возможности

- несколько отметок в день с ручным временем;
- иерархический выбор нескольких эмоций и необязательной интенсивности;
- отдельный выбор состояний, заметка, избранное и недавние чувства;
- точный HSL-цвет дня и личное название оттенка;
- календарь, детали дня, локальная статистика и палитра цветов;
- экспорт, системное «Поделиться», проверяемый импорт, объединение и замена данных;
- светлая, тёмная и системная тема;
- PWA: установка и работа офлайн после первого открытия.

## Стек

Vite, React, TypeScript, CSS, IndexedDB, `vite-plugin-pwa`, Lucide Icons.

## Запуск

```bash
npm install
npm run dev
```

Сборка и локальный просмотр production-версии:

```bash
npm run build
npm run preview
```

## Данные и приватность

Записи и настройки хранятся в IndexedDB текущего браузера (`tikhiy-den`). Бэкенда, аккаунтов, аналитики и скрытой передачи данных нет. JSON-копия содержит версию схемы, дни, записи, цвета и настройки. При импорте файл проверяется; режим объединения использует стабильные ID записей и `updatedAt`, чтобы не создавать дубликаты.

Для полной офлайн-работы сначала откройте уже собранное приложение один раз с доступом к сети. Service worker сохранит оболочку приложения в кэше.

## Важно

«Тихий день» — инструмент личного наблюдения, а не диагностическое или медицинское приложение. Цвета и записи не получают автоматических психологических интерпретаций.
